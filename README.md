> I dropped a spoon and it took eleven years to hit the floor.

`python3 main.py` writes the line as UTF-8 to `/output/entry.txt` with no trailing newline. Pass `--output-dir DIR` to write elsewhere.

`python3 -m unittest -v` runs the stdlib tests, including validation of empty, over-200 and whitespace-only text.
